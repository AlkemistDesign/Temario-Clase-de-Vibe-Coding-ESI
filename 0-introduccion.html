Conceptos clave

Vibe Coding

Técnica de programación donde se utilizan prompts para generar el código con IA. Esta recibe las descripciones detalladas y genera el código estructurado. El esfuerzo humano se desplaza completamente a la arquitectura, la estrategia y el pensamiento crítico.

Código Asistido por IA

A diferencia del vibe coding, aquí el humano sigue siendo quien escribe el código, pero cuenta con un asistente de IA que deduce lo que intenta hacer y autocompleta líneas o bloques de código. La IA se usa como un apoyo en vez de delegar todas las tareas.

LLM (Large Language Model)

Son motores predictivos del lenguaje que, dado un contexto (prompt + código), calculan estadísticamente cuál es la siguiente mejor secuencia de caracteres según su entrenamiento.

Conceptos clave

Ventana de Contexto

Es la cantidad máxima de información, medida en tokens, que un modelo de inteligencia artificial puede retener y procesar de forma simultánea durante una interacción. Incluye el mensaje actual, el historial de mensajes, las instrucciones del sistema y los archivos adjuntos.

Alucinaciones

Los LLMs predicen lenguaje, no diferencian una verdad de una mentira. Su entrenamiento se basa en parecerse al lenguaje humano; todo lo que responde una IA se lo inventa. Suele acertar, pero cuando falla lo llamamos alucinación, por esto es muy importante revisar y probar.

Refactorización

Proceso de reorganizar, limpiar y optimizar el código fuente sin alterar su comportamiento externo. Consiste en pedirle a la IA que lo estructure lógicamente en componentes y elimine redundancias para que el proyecto pueda crecer en el futuro sin colapsar.

Código de espagueti (Spaghetti Code)

Término para describir un programa informático cuya estructura de control es tan compleja, enredada y desorganizada que se parece a un plato de espaguetis.

Arquitectura web

Front-End

Es la parte pública de una aplicación, la que se carga en la pantalla del usuario. Engloba todo lo que se puede ver y con lo que se puede interactuar. Se encarga de traducir el código en una interfaz visual y de asegurar que el diseño se adapte a diferentes tamaños de pantalla.

Back-End

Es la infraestructura que opera en un servidor remoto. Su función es procesar las reglas del negocio, verificar la identidad de los usuarios, gestionar la seguridad y almacenar toda la información en bases de datos. Es lo que permite que una aplicación guarde y gestione datos.

API (Interfaz de Programación de Aplicaciones)

Conjunto de reglas que permite que dos sistemas informáticos se comuniquen. Es el canal a través del cual el Frontend solicita información, ya sea a nuestro backend o a servicios de terceros.

Ecosistema y herramientas

IDE (Entorno de Desarrollo Integrado)

Es el editor de código donde se redacta, organiza y revisa el código fuente de un proyecto. Los IDEs modernos incorporan IA en la interfaz, permitiendo generar o modificar el código sin salir del espacio de trabajo.

Terminal / Consola de Comandos

Herramienta basada en texto que permite dar instrucciones directas al sistema operativo. Se utiliza para tareas de administración del proyecto, como instalar dependencias, iniciar el servidor de prueba o preparar el proyecto para su publicación.

Despliegue y Hosting

Despliegue: Proceso técnico de empaquetar y optimizar el código terminado.
Hosting: Servidor público donde se aloja ese código para estar disponible mediante un dominio web.

Git

Sistema de control de versiones que funciona como un registro histórico de cada cambio realizado en los archivos del código. Permite trabajar en nuevas características de forma segura y volver a versiones anteriores.

GitHub

Plataforma en la nube diseñada para alojar y gestionar proyectos controlados mediante Git. Facilita el trabajo en equipo, la revisión de código y actúa como el estándar profesional para almacenar software.

Metodologías y bases

HTML

Lenguaje estándar utilizado para estructurar el contenido de una página web. Define la jerarquía de la información (títulos, párrafos, enlaces, imágenes). No contiene información de diseño.

CSS

Lenguaje que define la presentación visual de la estructura HTML. Gestiona colores, tipografía, márgenes, distribución y diseño responsivo. Son las propiedades visuales que lo hacen atractivo.

JavaScript

Lenguaje de programación que dota de interactividad y lógica a la web. Permite reaccionar a acciones del usuario, validar formularios y actualizar información sin recargar la página.

Diferencia entre Java y JavaScript

Java y JavaScript son lenguajes totalmente distintos. No es una abreviatura: JavaScript añade dinamismo en la web, Java impulsa sistemas empresariales y plataformas como Minecraft.

Arquitectura de Componentes

Forma de estructurar proyectos donde la interfaz se construye como un conjunto de piezas reutilizables (ej. botones, barras de navegación), facilitando la coherencia y el mantenimiento.

Frameworks y Librerías

Código preescrito y estandarizado que resuelve problemas comunes de desarrollo. Proveen una base probada para no empezar desde cero en cada proyecto.

Tecnologías front-end

HTML y CSS

Lenguajes de marcado y estilo base que definen estructura y apariencia visual.

Uso: Proyectos muy pequeños o fundamentos básicos.

JavaScript (JS)

El lenguaje nativo de la web. En aplicaciones grandes suele combinarse con frameworks para evitar código desorganizado.

Uso: Proyectos ligeros o interactividad directa.

TypeScript (TS)

JavaScript con tipado estricto que previene errores en tiempo de desarrollo antes de compilar.

Uso: Estándar en proyectos profesionales modernos.

Tailwind CSS

Clases utilitarias predefinidas directamente en el marcado para maquetar interfaces modernas con rapidez.

Uso: Construcción ágil de UI con diseño consistente.

Tecnologías front-end

React

Librería basada en componentes reactivos y dinámicos con un ecosistema masivo.

Uso: Aplicaciones web dinámicas y SPAs.

Vue.js

Framework progresivo que integra HTML, CSS y JS con una curva de aprendizaje muy fluida.

Uso: Proyectos con foco en orden y desarrollo rápido.

Angular

Framework robusto y estructurado desarrollado por Google con TypeScript obligatorio.

Uso: Grandes aplicaciones corporativas.

Node.js (Herramientas Front)

Entorno necesario para compilar y procesar frameworks modernos y Server-Side Rendering.

Uso: Build tooling y proyectos basados en frameworks.

Tecnologías back-end

Node.js (JS / TS)

Permite utilizar el mismo lenguaje en cliente y servidor para APIs rápidas y tiempo real.

Uso: Aplicaciones en tiempo real, APIs y stacks JavaScript unificados.

Java

Máxima estabilidad, tipado fuerte y rendimiento excelente en procesos concurrentes masivos.

Uso: Banca, seguros y sistemas críticos de gran escala.

PHP

Ecosistema maduro con soporte universal en casi cualquier proveedor de hosting y CMS populares.

Uso: Sitios web, portales de contenido y comercio electrónico.

Python

Sintaxis concisa y legible, líder absoluto en IA, ciencia de datos y automatización.

Uso: Servicios de Inteligencia Artificial, análisis de datos y prototipado rápido.

El cambio de era: No estamos ante la obsolescencia del programador, sino ante su evolución hacia un rol de supervisor crítico: la IA genera el volumen y el humano garantiza la veracidad, arquitectura y seguridad.

1. Crear software no es programar

El mercado ya no paga por teclear líneas de código aisladas, sino por entender problemas, diseñar sistemas y orquestar soluciones de software completas.

2. Los fundamentos importan más que nunca

Antes se requería Lenguaje + Framework. Hoy el nuevo estándar es Fundamentos de Ingeniería + Inteligencia Artificial para poder validar lo que la máquina produce.

3. Tú diriges, la IA ejecuta

4. Utilizar IA no es opcional

No te reemplaza la IA; te reemplaza un desarrollador que sabe dirigirla con criterio técnico profesional y rigor metodológico.

Fundamentos de los LLM

¿Cómo funciona un LLM? (Inferencia)

Predice tokens por probabilidad

Un Large Language Model (LLM) es un modelo entrenado con ingentes volúmenes de texto para aprender patrones del lenguaje. Su ciclo de respuesta consiste en:

1. Entrada: Recibe el mensaje y contexto.
2. Tokenización: Fragmenta el texto en unidades o tokens.
3. Predicción: Calcula y emite el siguiente token más probable.

* Regla fundamental: El modelo no "piensa" en el sentido humano; calcula probabilidades estadísticas.

Número de Parámetros

Son las "conexiones neuronales" que almacenan lo aprendido. Cuantos más parámetros posee, mayor es su capacidad de capturar conocimiento y patrones complejos.

Tokens

Unidades mínimas en las que se procesa la información (sílabas o fragmentos de palabras). Los LLMs leen, calculan y tarifican su uso en base a tokens.

Temperatura

Ajuste que regula la aleatoriedad durante la inferencia: valores bajos (0.0 - 0.2) dan respuestas exactas y deterministas (código); valores altos fomentan creatividad.

Ventana de Contexto

"Memoria a corto plazo" del modelo. Si un proyecto excede este límite de tokens, la IA olvida requisitos iniciales o empieza a alucinar.

Multimodalidad

Capacidad del modelo para procesar y relacionar múltiples tipos de entrada simultáneamente: texto, imágenes, diagramas, capturas y audio.

Razonamiento vs. Rapidez

Los modelos convencionales responden de forma inmediata; los modelos de razonamiento pausan, planifican y verifican internamente sus pasos antes de emitir la respuesta.

Latencia

Tiempo de espera medido desde que se pulsa "Enviar" hasta que el modelo emite el primer token (Time-to-First-Token).

Alucinaciones

Mayor defecto de los LLMs. Ocurre cuando el modelo no dispone de datos certeros y genera información falsa con apariencia de verdad.

Modelos y herramientas

Pesos Abiertos vs. Pesos Cerrados

Pesos abiertos: Permiten descargar y acceder a los parámetros del modelo para adaptarlo o auditarlo. (Nota: Pesos abiertos no siempre significa código abierto completo de datos y entrenamiento).
Pesos cerrados: Acceso exclusivo mediante API o plataformas en la nube.

Ejecución en Nube vs. Local

Nube (Cloud): Máxima potencia de cómputo y sin requisitos de hardware local, mediante suscripción/API.
Local: Privacidad absoluta y funcionamiento sin conexión a internet, ejecutándose directamente en la GPU del equipo.

Criterio de Selección: Potencia ↔ Velocidad ↔ Coste

🧠 Modelo Potente (Razonamiento)

Para pensar, diseñar la arquitectura de la aplicación, debatir requisitos y resolver bugs complejos.

⚡ Modelo Medio

Equilibrio perfecto para el desarrollo diario, creación de componentes y refactorización continua.

🏎️ Modelo Rápido y Barato

Para autocompletado inline de líneas, tareas mecánicas, linting, formateo y transcripciones.

Prompting y Vibe Coding

Estructura de prompts efectivos y comparación de metodologías de trabajo.

Prompt Engineering Clásico

  1. Rol (¿Quién soy?): Define experiencia y especialidad.
  2. Contexto (¿Dónde estamos?): Proyecto, stack y problema.
  3. Tarea exacta (¿Qué necesitas?): Objetivo específico.
  4. Restricciones (¿Qué límites hay?): Convenciones y reglas.
  5. Formato de salida (¿Cómo lo quieres?): Estructura esperada.

Prompt Engineering 2026 (Divagación Guiada)

Patrón basado en sesiones conversacionales por voz o texto fluido: se exponen ideas en bruto y se pide al LLM que actúe como entrevistador crítico en pocos turnos para reconstruir y estructurar los pensamientos antes de generar una sola línea de código.

"Mejorar la fusión de mentes para tener que corregir menos cosas a posteriori." — Andrej Karpathy

Vibe Coding Puro

Programar guiándose por intuición y ayuda de IA para generar código a máxima velocidad. Describir y aceptar sin revisar en profundidad: rápido, divertido y peligroso.

Ingeniería de Software

Diseñar y construir software de forma sistemática con arquitectura modular, arneses de control, pruebas automatizadas y mantenimiento garantizado a largo plazo.

Agentes y Harness

El salto a los flujos agénticos autónomos y arneses de ingeniería.

Harness Engineering (Arneses y Guardarraíles)

Para un ingeniero de software, usar un chat convencional para programar es una ineficiencia estratégica. El salto cualitativo hacia los flujos agénticos permite operar en un nivel de abstracción superior: validar intenciones en lugar de corregir líneas de código aisladas.

¿Qué es un Agente de Código?

Objetivo + Herramientas + Bucle

Es un sistema que utiliza un LLM para realizar tareas orientadas a un objetivo, encadenando decisiones y acciones de forma autónoma: puede planificar, consultar archivos, usar herramientas de terminal, modificar código y verificar resultados bajo tu supervisión.

El Bucle del Agente
1. Entiende
2. Planifica
3. Actúa
4. Evalúa
5. Ajusta ↺

Diferencias clave: Chat vs. Agente

💬 Chat Convencional
  • • Pregunta → Respuesta aislada
  • • Sin acceso directo al sistema de archivos
  • • Un solo turno de ejecución
  • • Requiere copiar y pegar manualmente
🤖 Agente Autónomo
  • • Bucle autónomo multi-paso
  • • Lee y escribe directamente en archivos
  • • Ejecuta comandos de terminal y verifica resultados
  • • Itera y corrige errores automáticamente
